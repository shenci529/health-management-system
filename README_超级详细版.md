## 一、这个系统是做什么的？

这是一个**幼儿和中小学生的健康管理平台**，主要功能包括：

### 👥 5种用户角色，各有各的功能：

| 角色 | 能做什么 |
|------|---------|
| **🏫 校级管理员** | 管理全校用户、班级、查看所有健康数据、导出报表等 |
| **👨‍🏫 教师** | 管理班级健康、发布健康任务、查看传染病预警等 |
| **👨‍👩‍👧 家长** | 查看孩子健康数据、请假、和老师沟通等 |
| **👦👧 学生** | 健康打卡、完成任务、查看自己的健康档案等 |
| **👨‍⚕️ 校医** | 处理健康异常、管理隔离、提供健康指导等 |

## 三、如何启动系统？（超详细步骤）

### 🚀 方法一：一键启动（推荐！小白首选）

如果你用的是 **Windows** 电脑，这是最简单的方法：

1. 打开项目文件夹，找到 `start.bat` 文件
2. **双击** `start.bat`
3. 等待它自动执行（会自动安装依赖、初始化数据库、启动服务）
4. 浏览器会自动打开系统页面
5. 完成！开始使用吧！

---

### 🔧 方法二：手动启动（想了解更多的可以试试）

如果你想手动一步步启动，或者你的系统不是Windows：

#### 第一步：检查是否安装了 Node.js

首先，你需要安装 **Node.js**（这是运行这个系统必须的环境）

1. 打开浏览器，访问：https://nodejs.org/
2. 下载并安装 LTS 版本（长期支持版，更稳定）
3. 安装完成后，打开命令行（按 `Win+R`，输入 `cmd`，回车）
4. 输入 `node -v`，如果显示版本号，说明安装成功！

#### 第二步：安装前端依赖

1. 在项目文件夹中，按住 `Shift` 键，同时点击鼠标右键
2. 选择「在此处打开 Powershell 窗口」或「在此处打开命令行窗口」
3. 输入命令：
   ```
   npm install
   ```
4. 等待安装完成（第一次可能需要几分钟）

#### 第三步：安装后端依赖

1. 在命令行中，进入 `server` 文件夹：
   ```
   cd server
   ```
2. 安装后端依赖：
   ```
   npm install
   ```
3. 安装完成后，回到项目根目录：
   ```
   cd ..
   ```

#### 第四步：初始化数据库

在命令行中输入：
```
npm run db:init
```
这会创建数据库文件并添加一些演示数据。

#### 第五步：启动后端服务

打开一个**新的**命令行窗口，进入 `server` 文件夹，输入：
```
npm start
```
或者在项目根目录输入：
```
npm run server
```
看到提示「服务已启动」说明成功了！

#### 第六步：启动前端服务

再打开一个**新的**命令行窗口，在项目根目录输入：
```
npm run dev
```
看到提示「Local: http://localhost:3000」说明成功了！

#### 第七步：访问系统

打开浏览器，访问：http://localhost:3000

## 四、如何修改前端页面？

### 🎨 基础：Vue文件是什么？

前端页面都是 `.vue` 文件，一个Vue文件通常包含3部分：

```vue
<template>
  <!-- 第1部分：HTML结构（页面上显示什么内容） -->
</template>

<script>
  // 第2部分：JavaScript逻辑（页面的功能代码）
</script>

<style>
  /* 第3部分：CSS样式（页面的外观、颜色、排版等） */
</style>
```

---

### ✏️ 示例1：修改登录页的标题

假设你想把登录页的标题从「健康管理系统」改成「XX学校健康管理平台」

1. 打开文件：`src/views/Login.vue`
2. 找到 `<template>` 部分，找到标题文字
3. 修改成你想要的文字
4. **保存文件**
5. 刷新浏览器页面，就看到效果了！

---

### ✏️ 示例2：修改页面颜色

假设你想把按钮的颜色改成蓝色：

1. 打开对应的 `.vue` 文件
2. 找到 `<style>` 部分
3. 找到按钮的样式（通常有 `.button` 或 `.el-button` 这样的类名）
4. 修改 `background-color` 的值，比如：
   ```css
   .my-button {
     background-color: #409EFF;  /* 改成蓝色 */
   }
   ```
5. 保存并刷新

---

### 📝 修改提示：

- **修改HTML（`<template>`）** → 改页面内容（文字、图片、按钮位置等）
- **修改CSS（`<style>`）** → 改页面外观（颜色、大小、间距等）
- **修改JavaScript（`<script>`）** → 改页面功能（逻辑、数据处理等）

## 五、如何修改后端接口？

### 🔌 什么是接口？

简单说，接口就是前端和后端「对话」的方式。比如前端说「给我用户列表」，后端就通过接口把数据传回来。

---

### ✏️ 示例：修改用户列表接口

假设你想修改获取用户列表的逻辑：

1. 打开文件：`server/routes/users.js`
2. 找到 `router.get('/', ...)` 这个函数（这是获取用户列表的接口）
3. 修改里面的代码
4. **保存文件**
5. **重启后端服务**（修改后端代码后必须重启！）

---

### 💡 后端修改提示：

- `server/routes/` 文件夹下的每个文件对应一类接口
- 修改后端代码后，**必须重启后端服务**才能生效！
- 重启方法：在后端命令行窗口按 `Ctrl+C` 停止，再重新运行启动命令

## 六、如何修改数据库？

### 🗄️ 数据库是什么？

数据库就是存数据的地方，比如用户信息、健康记录都存在这里。这个系统用的是 **SQLite** 数据库（一个轻量级的数据库，不需要安装额外软件）。

---

### 📋 数据库文件位置

数据库文件在：`server/database/health_management.db`

---

### ✏️ 如何查看和修改数据库？

#### 方法1：用SQLite工具（推荐）

1. 下载一个SQLite可视化工具，比如：
   - DB Browser for SQLite（免费、好用）
   - 下载地址：https://sqlitebrowser.org/dl/

2. 安装后打开，点击「Open Database」
3. 选择 `server/database/health_management.db` 文件
4. 现在你可以看到所有的表和数据了！
5. 可以直接在工具里修改、添加、删除数据
6. 修改完记得点击「Write Changes」保存

#### 方法2：修改初始化脚本（重新生成数据库）

如果你想彻底重新设计数据库结构：

1. 打开文件：`server/database/schema.sql`
2. 修改里面的SQL语句（比如添加字段、修改表结构）
3. 删除旧的数据库文件：`server/database/health_management.db`
4. 重新运行初始化：
   ```
   npm run db:init
   ```

## 七、常见问题解答

### ❓ 1. 端口被占用怎么办？

如果启动时提示端口已被占用，可以：

- 前端默认端口是3000，后端是3002
- 可以修改 `vite.config.js` 改前端端口
- 可以修改 `server/server.js` 改后端端口

---

### ❓ 2. 如何把系统部署到服务器让别人访问？

这需要一些服务器知识，简单来说：

1. 买一台云服务器（阿里云、腾讯云等）
2. 在服务器上安装Node.js
3. 把项目文件上传到服务器
4. 在服务器上启动后端和前端
5. 配置域名和防火墙
6. 完成！

（如果需要详细的部署教程，可以单独搜索「Node.js项目部署」）

---

### ❓ 3. 我想添加一个新功能，应该怎么做？

添加新功能的一般步骤：

1. **前端部分**：
   - 在 `src/views/` 创建新的 `.vue` 页面
   - 在 `src/router/index.js` 添加路由配置
   - 在页面中编写功能代码

2. **后端部分**：
   - 在 `server/routes/` 中添加或修改接口
   - 如果需要新的数据表，修改 `server/database/schema.sql`

3. **测试功能**：
   - 启动前后端
   - 在浏览器中测试

---

### ❓ 4. 修改代码后页面没变化？

可能的原因：

- **前端**：没有保存文件，或者没有刷新浏览器
- **后端**：修改了后端代码但没有重启后端服务
- **缓存**：尝试按 `Ctrl+F5` 强制刷新浏览器

---

### ❓ 5. 如何恢复到初始状态？

如果你把代码改乱了想恢复：

1. 删除数据库文件：`server/database/health_management.db`
2. 重新初始化数据库：`npm run db:init`
3. 如果有代码备份，用备份替换修改的文件

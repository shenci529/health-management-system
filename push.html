🚀 一键推送代码到 GitHub

当前 Git 推送协议无法访问 GitHub，但通过浏览器 API 可以直接推送。

打开 https://github.com/settings/tokens/new，勾选 repo，生成 token 后粘贴到下方。

以下 4 个文件将被更新（自动读取当前网页所在文件夹的文件）：

• server/licenseService.js
• src/licenseService.js
• src/views/LicenseActivate.vue
• .gitignore

# 小程序图标说明

此目录需要放置以下图标文件（尺寸 81x81px，PNG格式）：

## 底部导航栏图标

- `home.png` - 首页图标（未选中）
- `home-active.png` - 首页图标（选中）
- `record.png` - 记录图标（未选中）
- `record-active.png` - 记录图标（选中）
- `assessment.png` - 评估图标（未选中）
- `assessment-active.png` - 评估图标（选中）
- `knowledge.png` - 知识图标（未选中）
- `knowledge-active.png` - 知识图标（选中）
- `profile.png` - 我的图标（未选中）
- `profile-active.png` - 我的图标（选中）

## 页面图标

- `user.png` - 用户图标
- `lock.png` - 锁图标

## 临时方案

在添加真实图标之前，可以使用 emoji 或纯文字代替，或者修改 app.json 暂时移除 tabBar 的 iconPath 配置。

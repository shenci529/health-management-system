## 🚀 3 步让系统永久在云端！

### 第一步：去 GitHub 建仓库
1. 打开 https://github.com
2. 登录或注册账号
3. 点右上角 + → New repository
4. 填仓库名称：`health`
5. 点 Create repository

### 第二步：把代码推送到 GitHub
在你的项目文件夹里，右键 → 打开命令行，输入：
```bash
git init
git add .
git commit -m "init"
git remote add origin https://github.com/你的用户名/health.git
git branch -M main
git push -u origin main
```

### 第三步：去 Railway 一键部署
1. 打开 https://railway.app
2. 点 Start a New Project
3. 选 Deploy from GitHub repo
4. 用 GitHub 登录
5. 选你的 health 仓库
6. 点 Deploy Now

---

✅ 等 2-3 分钟，就有了公网地址！
